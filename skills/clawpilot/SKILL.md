# Clawpilot

Source: https://clawhub.ai/jason513597/clawpilot

## Description

OpenClaw expert skill for gateway setup, chat channels, security hardening, multi-agent routing, deployment, and skill installation.

## Danbron Adapter

Use as an architecture/security reference for building Danbron Gateway:

- WhatsApp, Telegram, Discord, Slack, Signal, Teams channel adapters.
- Owner allowlists.
- Skill audit and supply-chain checks.
- Multi-agent routing and isolation.
- Session inspection and troubleshooting.

## Safety

- Do not run upstream scripts automatically.
- Treat all security checks as recommendations until ported into Danbron-specific scripts.

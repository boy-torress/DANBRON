## Description

Setup and hardening reference for gateway-style assistants.

## Capabilities

- Channel setup checklist.
- Agent/model/workspace settings.
- Security baseline.
- Tool permission recommendations.
- Automation and hook setup.
- Gateway deployment guidance.

## Danbron Adapter

Use to guide Danbron configuration screens and deployment docs.

## Safety

- Owner allowlist required for remote messaging channels.
- No public gateway without auth.
- No full command execution by default.
- Model fallback recommended.
